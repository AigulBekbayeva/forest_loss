# Forests in a Changing Climate — три карты лесов мира

Геопортал из трёх глобальных карт на одной странице: слева описание, переключатель карт и слоёв, справа интерактивная карта. Интерфейс на английском.

**Сайт:** https://aigulbekbayeva.github.io/forest_loss/

| | Карта | Что показывает |
|---|---|---|
| Map 01 | **Where Are the World's Forests?** | Доля леса (сомкнутость крон ≥ 30 %) в каждой ячейке 0,1° и средняя сомкнутость крон, 2000 г. |
| Map 02 | **Where Are Forests Losing the Climate Battle?** | Изменение климата лесов к 2041–2060 гг. относительно 1995–2014 гг.: индекс климатического стресса, потепление, осадки, дефицит упругости водяного пара (VPD); сценарии SSP2-4.5 и SSP5-8.5 |
| Map 03 | **Which Forests Are Most Vulnerable to Climate Change?** | Сводный индекс уязвимости из четырёх компонентов: потеря лесов, пожары, засушливость, климатический стресс; веса настраиваются ползунками |

Возможности портала:

- наведение на карту показывает страну и значение слоя, клик открывает карточку ячейки со всеми показателями карты;
- в Map 02 карточка сравнивает оба сценария, в Map 03 показывает процентиль каждого компонента;
- рейтинг «топ-10 стран» пересчитывается под выбранный слой, сценарий и веса; наведение на строку обводит страну на карте, клик приближает к ней;
- адрес карты сохраняется в ссылке: `#m1`, `#m2`, `#m3`.

## Данные

| Источник | Что взято | Разрешение |
|---|---|---|
| Hansen et al. 2013, Global Forest Change **v1.13** (UMD/Google/USGS/NASA) | `treecover2000`, `loss` 2001–2025 | 30 м → 0,1° |
| MODIS **MCD64A1** v6.1 | выгоревшая площадь 2001–2025 | 500 м → 0,1° |
| **TerraClimate** (Abatzoglou et al. 2018) | осадки и потенциальная эвапотранспирация, норма 1991–2020 | ~4 км → 0,1° |
| **NEX-GDDP-CMIP6** (Thrasher et al. 2022) | `tas`, `pr`, `hurs`; среднее 5 моделей: ACCESS-CM2, GFDL-ESM4, MIROC6, MPI-ESM1-2-HR, MRI-ESM2-0 | 0,25° |
| Natural Earth 1:50m (пакет `world-atlas`) | границы стран | — |

Охват 60° ю. ш. – 80° с. ш.

## Методика

**Map 01.** Лес — пиксель 30 м с сомкнутостью крон не менее 30 % в 2000 г. Это «древесный покров», а не лес в смысле FAO: плантации тоже учитываются. В GEE пиксели агрегированы до 0,1° (≈ 11 км): получены доля леса в ячейке и средняя сомкнутость. Площади считаются по реальной площади ячейки на сфере, ячейка относится к стране, в которую попадает её центр.

**Map 02.** Для каждой модели берутся средние за 2041–2060 гг. (сценарий) и 1995–2014 гг. (historical), затем модели усредняются. Показатели:

- потепление ΔT, °C;
- изменение годовых осадков ΔP, %;
- изменение VPD, кПа. VPD считается по формуле Тетенса из средних температуры и относительной влажности: абсолютное значение занижено, поэтому показано только изменение.

Индекс стресса — среднее трёх компонентов (ΔT, −ΔP, ΔVPD), каждый нормирован в 0–1 между 2-м и 98-м процентилями по лесным ячейкам обоих сценариев сразу, поэтому сценарии на одной шкале. Климат с 0,25° билинейно интерполирован на 0,1° и показан только в ячейках, где лес занимает не меньше 10 % площади.

**Map 03.** Каждый компонент переводится в процентиль среди мировой площади лесов (взвешивание по площади леса в ячейке):

1. потеря лесов — доля леса 2000 г., потерянная в 2001–2025 гг.; учитываются любые полные потери древостоя: расчистка, рубки, плантации, пожары;
2. пожары — средняя доля ячейки, выгорающая за год;
3. засушливость — индекс аридности P/PET; чем суше, тем выше балл;
4. климатический стресс — индекс Map 02 по SSP2-4.5.

Сводный балл — взвешенное среднее процентилей (по умолчанию веса равны). Классы — пятые доли мировой площади лесов: «Very high» всегда означает 20 % лесов с наибольшим баллом. Это относительный индекс: он показывает, где давления накладываются друг на друга сильнее, чем в других лесах, а не вероятность гибели леса.

### Ограничения

- Пять моделей CMIP6 дают центральную оценку; по осадкам модели расходятся сильнее всего.
- В пожарном компоненте много нулей: ячейки без пожаров получают одинаковый средний ранг этой группы.
- Потери Hansen включают плановые рубки и ротацию плантаций, поэтому в регионах интенсивного лесного хозяйства (Скандинавия, юго-восток США) компонент потерь высокий.
- Граница стран определяется по центру ячейки 0,1°: для малых островных государств итоги приблизительны.

## Структура репозитория

```
index.html                 страница портала
assets/app.js              логика карты: декодирование слоёв, раскраска, запросы, рейтинги
assets/style.css           стили
assets/vendor/             MapLibre GL JS 5 (лицензия BSD-3)
data/*.png                 слои: 8-битные PNG 3600×1400, 0,1°, код 0 = нет данных
data/meta.json             шкалы декодирования, таблицы процентилей, ключевые цифры
data/countries.png         индекс страны в каждой ячейке
data/countries.geojson     границы стран для карты (разрезаны по 180°)
data/countries-50m.json    исходный TopoJSON Natural Earth
raw/                       исходные GeoTIFF, выгруженные из Google Earth Engine
scripts/gee_export_v2.js   скрипт экспорта GEE (Hansen, MODIS, CMIP6)
scripts/gee_export_v1.js   первая версия; из неё использован только TerraClimate
scripts/build_data.py      raw/ → data/
```

Каждый слой — PNG в оттенках серого: значения квантованы в 255 уровней по линейной, квадратно-корневой или логарифмической шкале (параметры в `meta.json`). Браузер читает коды, раскрашивает их, перепроецирует строки в Web Mercator и передаёт MapLibre как canvas-источник. Те же коды используются для подсказок, карточек и рейтингов стран, поэтому сервер не нужен.

## Как пересобрать

```bash
# 1. Google Earth Engine: запустить scripts/gee_export_v2.js (и TerraClimate из v1),
#    положить GeoTIFF в raw/
# 2. Python 3.10+
pip install numpy scipy rasterio pillow shapely
python scripts/build_data.py
# 3. Локальный просмотр (fetch не работает с file://)
python -m http.server 8000   # → http://localhost:8000
```

Сайт статический, публикуется через GitHub Pages из ветки `main`, корень репозитория.
